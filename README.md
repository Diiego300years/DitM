# DitM

Technology / AI / software brand.

## Brand assets

The repository is the source of truth for the DitM web brand pack.

- `public/brand/ditm-logo.svg` — primary horizontal logo
- `public/brand/ditm-logo-light.svg` — logo for dark backgrounds
- `public/brand/ditm-mark.svg` — standalone DM mark
- `public/favicon.svg` — favicon
- `docs/brand/BRAND.md` — colors, typography and usage rules

The selected visual direction is the geometric **DM monogram + DitM wordmark + blue accent**.

## Web starter

The brand components are prepared for a Next.js / React implementation:

- `src/components/BrandLogo.tsx`
- `src/components/Navbar.tsx`
- `src/components/Hero.tsx`
- `src/styles/brand.css`
